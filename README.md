# Solar Powered Intelligent Equipment Monitoring and Predictive Maintenance System

An interactive 3D simulation of a solar-powered monitoring node on a mining haul truck. The node reads temperature, vibration and current, filters out noise from rough terrain, compares readings with safe limits, and either logs the data or raises an alarm, following the system flowchart.

## Live demo

Once GitHub Pages is enabled (see below), the simulation runs at:

`https://<your-username>.github.io/solar-equipment-monitor/`

## Features

- Detailed 3D haul truck with a solar panel, monitoring enclosure, sensors and warning beacon
- **Explain the system:** a 14-step guided walkthrough that follows the flowchart, bringing each component to the centre of the screen with an explanation and live readings
- **Break apart:** an exploded view showing every component and where it is mounted
- **Presentation mode:** full-screen 3D view with the flowchart in the corner
- Live flowchart showing the current step of the loop
- Adjustable conditions: speed, payload, terrain roughness, air temperature, time of day and cloud cover
- Fault injection: worn wheel bearing, cooling problem, electrical fault
- Tunable edge logic: loop rate, averaging window and alarm limits
- Solar energy model: panel size, battery type and capacity, node power draw

## System flow

1. **START:** solar panel, MPPT charge controller, LiFePO4 battery and MCB power the node
2. **Initialise** the microcontroller and sensors
3. **Read** temperature, vibration and current
4. **Filter / average** readings to ignore bumps from rough terrain
5. **Compare** with normal limits
6. **Normal:** log data for trend analysis
7. **Abnormal:** send a wireless alert and flash the warning beacon
8. **Loop back** and repeat

## Controls

| Action | Input |
|---|---|
| Orbit camera | Drag |
| Zoom | Scroll or pinch |
| Explain a part | Click it on the truck or in the flowchart |
| Rotate a focused part | Drag |
| Next / previous step | Right / left arrow keys |
| Close explanation | Esc |
| Break apart | E |

## Running locally

Open `index.html` in a modern web browser (Chrome, Edge or Firefox). An internet connection is needed the first time to load three.js and fonts.

## Publishing with GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute or two the site is live at the address shown on that page.

## Notes

Sensor readings are generated by simple models of each operating condition, for demonstration purposes. They are not measured truck data.

## Built with

- [three.js](https://threejs.org/) r128 for 3D rendering
- Plain HTML, CSS and JavaScript, no build step
